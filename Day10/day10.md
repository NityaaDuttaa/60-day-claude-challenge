# Day 10 – Portfolio Website with Claude

## Objective

Create a personal portfolio website using Claude and customize it with my own information.

## What I Did

* Used Claude to generate a complete portfolio website.
* Replaced the placeholders with my personal information.
* Added my projects, skills, achievements, and other relevant details.
* Saved the generated HTML file.
* Opened and tested the website in my browser.
* Took screenshots of the completed portfolio.

## Technologies Used

* HTML
* CSS
* JavaScript
* Claude AI

## Key Learnings

* Learned how AI can help generate a complete website from a detailed prompt.
* Learned how to customize AI-generated code according to my requirements.
* Practiced testing and debugging a generated website.
* Understood the importance of providing clear and specific information in prompts.

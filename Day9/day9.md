## 📱 Project: NutriScope

NutriScope is a nutrition-focused web application designed to help users enter their personal information, log food intake, and analyze their nutrition-related data.

### MVP Version

The first version focused on establishing the core functionality and structure of the application.

**Key features included:**

* User profile inputs
* Age, gender, height, and weight
* Activity level
* Dietary preference
* Food logging
* Food quantity and unit selection
* Editable food table
* Remove food entries
* Basic nutrition tracking

### Enhanced Version

The second version was created by providing an enhancement prompt to Claude.

The enhanced version improved the overall application by refining the interface, functionality, usability, and presentation.

## 🔍 Comparison

| Aspect              | MVP Version            | Enhanced Version                   |
| ------------------- | ---------------------- | ---------------------------------- |
| UI Design           | Basic interface        | More polished interface            |
| Functionality       | Core features          | Improved functionality             |
| User Experience     | Simple                 | More interactive and user-friendly |
| Visual Presentation | Basic                  | More refined                       |

## 💡 Key Learnings

* AI can generate a functional web application from a well-structured prompt.
* Iterative prompting can significantly improve an existing application.
* A detailed enhancement prompt produces better results than repeatedly asking for generic improvements.
* Comparing different versions helps identify which changes actually improve usability.
* Testing the generated application is important because AI-generated code can still contain bugs or incomplete functionality.
* Claude can be used not only for generating code but also for rapidly iterating on an existing project.


## 🚀 Conclusion

Day 9 demonstrated how AI-assisted development can be approached as an iterative process. Instead of stopping after generating the first working version, the application was enhanced through additional prompting and then compared against the original MVP.

This helped me understand the importance of **prompt quality, iterative development, testing, and evaluation when building applications with AI.**
